# Your own CRM vs. Bitrix24

Partner deck served at https://crm-iceberg.bitrix24.site.

The site's "HTML code" block loads `deck.html` from this repository, so editing `deck.html` here updates the site within a few minutes. The file is self-contained (CSS, JS, images inline), available in EN, ES, PT, DE, PL, TR and AR (right-to-left), with Bitrix24 prices per regional site and currency. Language and currency are chosen from the globe button at the top right.

Use `?lang=en|es|pt|de|pl|tr|ar` and `?cur=USD|EUR|GBP|MXN|BRL|PLN|TRY` in the site address to open it in a given language and currency.

Turkish lira (TRY) values are converted from the US$ prices of bitrix24.com.tr at the ECB reference rate; Bitrix24 does not sell in TRY.
