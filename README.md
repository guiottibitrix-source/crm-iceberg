# Your own CRM vs. Bitrix24

Partner deck served at https://crm-iceberg.bitrix24.site.

The site's "HTML code" block loads `deck.html` from this repository, so editing `deck.html` here updates the site within a few minutes. The file is self-contained (CSS, JS, images inline), available in EN, ES, PT, DE and PL, with Bitrix24 prices per regional site and currency.

Use `?lang=pt|es|de|pl|en` and `?cur=USD|EUR|GBP|MXN|BRL|PLN` in the site address to open it in a given language and currency.
